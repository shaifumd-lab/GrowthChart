📊 GrowthChart v2.0 — Help

🚀 Quick Start

  1. Click + Patient to create a new patient (or 📄 Import to import from a PDF/Excel file)
  2. Select a patient from the sidebar to view their growth chart
  3. Click + Measurement to add height/weight data
  4. Toggle between WHO and CDC standards
  5. Use 📤 PDF to export an Elysia-branded report

📏 Growth Charts

  • Height / Weight / BMI / Velocity tabs switch between chart types
  • WHO ⟷ CDC toggles the reference standard
  • Charts show percentile curves: P3, P5, P10, P25, P50, P75, P90, P95, P97
  • Data points display SDS (z-score) to 2 decimal places
  • Hover over any point for detailed info

🔍 Zoom & Navigation

  • Drag on the chart to zoom into a region
  • Double-click to reset zoom to original view
  • Scroll wheel to zoom in/out
  • Click 🔍 Reset button to restore default view
  • Use the Plotly toolbar (top-right of chart) for additional controls

📄 Import Data

  • PDF — Hebrew clinic letters are parsed automatically (patient name, DOB, measurements, parental heights)
  • Excel / CSV — columns are auto-detected (supports Hebrew and English headers)
  • Multiple files — drop several files at once for batch import
  • Assign to an existing patient via the dropdown, or let auto-detection find matches
  • Review extracted data before confirming the import

👨‍👩‍👦 Parental Heights & MPH

  • Edit a patient → enter Father and Mother heights
  • MPH (Mid-Parental Height) auto-calculates: Boys = (F+M+13)/2, Girls = (F+M-13)/2
  • MPH can be manually overridden if the clinic letter states a different value
  • Target height range shown as a green band on the height chart (MPH ± 8.5cm boys / ± 7.5cm girls)
  • Parental heights are auto-extracted from Hebrew clinic PDFs when available

🦴 Bone Age

  • Enter bone age (years) when adding a measurement
  • A purple diamond marker appears on the height chart showing height-for-bone-age
  • If bone age is available, Bayley-Pinneau Predicted Adult Height appears as a star at age 18

📈 Growth Velocity

  • Click the Velocity tab to see height velocity (cm/year) between consecutive measurements
  • Reference curves (P3–P97) from Tanner data are shown for comparison
  • Requires at least 2 height measurements at different ages

🧬 Syndromic Charts

  • Edit a patient → set Syndrome (Turner or Down)
  • Syndromic reference curves appear in purple alongside normal WHO/CDC curves
  • Turner syndrome: girls only (Lyon et al. reference)
  • Down syndrome: boys and girls (Zemel et al. 2015 reference)

📤 Export

  • 📤 PDF — Elysia-branded 2-page report (Height+Weight on page 1, BMI+data table on page 2)
  • 🖼️ PNG — Current chart as image with informative filename
